# H5P Dialogue Cards Papi Jo

This is a fork of the official version of the H5P Dialogue Cards content by "papi Jo"
Tutorial, examples and more details on the papi Jo Drupal test site at http://www.rezeau.org/drupal/

## Development

The editable implementation lives under `src/`:

- `src/scripts/h5p-dialogcards.js` registers the public
  `H5P.DialogcardsPapiJo` function constructor.
- `src/styles/h5p-dialogcards.css` is the editable stylesheet.
- `src/entries/h5p-dialogcards.js` is the Webpack entry point. It imports the
  stylesheet and loads the implementation for its `H5P` namespace side effect.

The files in `dist/` are generated by Webpack. Do not edit them manually. The
top-level `dialogcards.css` is a legacy file and is not loaded by `library.json`.

### Prerequisites and installation

Use a supported Node.js release with npm. Install the exact dependency versions
recorded in `package-lock.json`:

```sh
npm ci
```

### Build and watch mode

Create a minified production bundle and extracted stylesheet:

```sh
npm run build
```

Rebuild when source files change during development:

```sh
npm run watch
```

### Linting

Run both JavaScript and CSS linting:

```sh
npm run lint
```

The individual checks are available as `npm run lint:js` and
`npm run stylelint`.

### H5P runtime contract tests

Build the production bundle and run the Phase 2A runtime tests with:

```sh
npm test
```

`npm run test:runtime` is the equivalent narrower command. See
[`TESTING.md`](TESTING.md) for the H5P Core boundary represented by the test
harness, its test-only stubs, and its current limitations.

### Built-artifact verification

Build and verify the production artifacts with:

```sh
npm run verify
```

The verification confirms that the files referenced by `library.json` exist
and that the JavaScript bundle registers `H5P.DialogcardsPapiJo`. To check an
already-built `dist/` directory without rebuilding it, run
`npm run verify:dist`.

`library.json` loads these generated files at runtime:

- `dist/h5p-dialogcards.js`
- `dist/h5p-dialogcards.css`

Generated `dist/` files are ignored by Git in this repository. Release
packaging must run the production build and include the generated files even
though they are not committed.
